# Semana Tecnológica UCPel 2026

Projeto acadêmico de Landing Page para o Projeto Integrador IV-A.

## Como abrir no Windows 10
1. Extraia o ZIP.
2. Abra a pasta `semana-tecnologica-ucpel-2026`.
3. Dê dois cliques em `index.html`.
4. A página abrirá no navegador.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: visual, layout e responsividade.
- `script.js`: menu mobile e slideshow.
- `assets/`: imagens locais do banner.

IMAGENS E IDENTIDADE VISUAL
- O cabeçalho utiliza a marca UCPel presente no briefing oficial do projeto.
- O slideshow possui três imagens locais produzidas especificamente para esta versão acadêmica, relacionadas aos temas do evento: tecnologia, desenvolvimento web, inteligência artificial, dados e inovação.
- As imagens são ilustrativas e não representam fotografias da edição 2026. Isso evita atribuir ao evento imagens de outras edições ou eventos.
- As imagens são locais para que o slideshow funcione mesmo quando o projeto for aberto diretamente pelo arquivo index.html.
